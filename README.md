# 🌤️ Weather App

A simple weather app built with React + Vite that shows real-time weather for any city.

## ✨ Features
- 🔍 Search weather by city name
- 🌡️ Shows temperature, condition, humidity, feels-like
- 🎨 Beautiful gradient UI with glassmorphism
- ⚠️ Error handling (city not found, network errors)

## 🛠️ Tech Stack
- **React** — UI
- **Vite** — Build tool
- **OpenWeatherMap API** — Weather data
- **CSS3** — Styling
